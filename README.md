> [!NOTE]
> **Focus area: Application Security & Secure Software Engineering.** I build the software first, then secure it — hardening real backends (JWT, rate limiting, dependency auditing), and building the detection tools themselves (a SIEM, an ML-based smishing classifier) rather than only operating someone else's. That's the lane I'm going deep on.

<br/>

### 🧭 About

I'm a CS student who ended up specializing by accident — I kept building full products (mobile app → backend → ML service, all wired together and actually working), and the parts I cared most about fixing were always the security-shaped ones: the auth flow with no rate limiting, the endpoint leaking too much in an error message, the dependency with a known CVE. That turned into a deliberate focus.

- 🔭 **Currently building:** [bantAI](https://github.com/gncrlatienza-eng/bantAI) — Android app that intercepts and classifies SMS smishing in real time (Kotlin/Compose + NestJS + a fine-tuned XLM-RoBERTa model) — and TruePositive, a SIEM built to teach detection fundamentals instead of burying beginners in enterprise-console jargon.
- 🎯 **Going deeper on:** application security, secure-by-default backend design, and ML-assisted threat detection — via hands-on mentorship at **Dysrupt IT**.
- 🌱 **Also learning:** CI/CD security gates, dependency + SAST scanning as a standard part of shipping, not an afterthought.
- ⚡ **Outside the stack:** Arduino hardware projects — a button-controlled LED game with on-device menu navigation, sensor work with DHT temp/humidity modules.
